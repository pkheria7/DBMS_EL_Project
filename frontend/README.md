# Frontend - TeamSync EL Portal

This is the frontend application for TeamSync EL Portal, built with React and Vite.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

- `/src/components` - Reusable React components
- `/src/pages` - Page components
- `/src/api` - API client configuration
